# 🐾 Casa de Ração

Página inicial de um site institucional para uma loja de produtos para pets,
desenvolvida como projeto pessoal para praticar front-end.

## Tecnologias
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Página inicial (`index.html`) com apresentação da loja
- Página de cadastro (`cadastro.html`) para captura de dados de clientes

## Status
Projeto em pausa — desenvolvido como prática de HTML, CSS e JS puro.
Próximos passos planejados: responsividade mobile e integração com backend
para persistência real dos cadastros.

## Como rodar
Clone o repositório e abra o arquivo `index.html` no navegador.

```bash
git clone https://github.com/yMrlx/casa-de-racao.git
```
